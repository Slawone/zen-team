# zen-team
Repository for collaborative development of an educational project

## Установка:
  1. Клонировать репозиторий (git clone ...)
  2. Установить записимости (npm install)
  3. Создать отдельную ветку (git -checkout -b ...)

## Запуск проекта
  1. Запустить компилятор sass (sass --watch ...)
  2. Запустить Live Server
